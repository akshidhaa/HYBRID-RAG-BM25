# HYBRID-RAG-BM25
This project adds a Confidence-Aware Abstention Layer on top of a hybrid BM25 and semantic retrieval pipeline and measures how trustworthy the retrieved evidence is using three signals: retrieval strength (S1), rank agreement between the BM25 and semantic rankers (S2), and citation groundedness of the answer (S3).
